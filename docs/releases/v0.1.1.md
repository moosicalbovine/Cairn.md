# Cairn.md v0.1.1 — clearer guidance and safer upgrades

Cairn.md v0.1.1 is a patch release for the Windows MVP. It keeps the v0.1.0
feature scope while improving startup recovery guidance, repository accuracy,
and release validation.

## What changed

- Startup failures retain available diagnostic details and explain how to
  restart Cairn.md after closing the fallback screen.
- The README, user guide, architecture notes, contribution guidance, and product
  scope now match the shipped application and measured performance contract.
- Historical scope notes clearly label later reference corrections without
  rewriting the decisions recorded at the time.
- Windows release validation now upgrades from v0.1.0 and runs the installed
  workflow again against the existing library.
- Performance and installer checks run on separate clean Windows jobs so build
  activity cannot contaminate either result.

## Install or upgrade

Download the x64 `.exe` and matching `.sha256` file from this release. Verify the
checksum, then run the current-user installer. Administrator credentials are not
required. You can install v0.1.1 over v0.1.0; the release workflow verifies that
the existing library remains usable after the upgrade.

This installer is **unsigned** and may trigger Microsoft Defender SmartScreen.
Verify that it came from this GitHub release and that its SHA-256 checksum
matches before deciding whether to run it.

Cairn.md uses Microsoft Edge WebView2. Most current Windows systems already have
the runtime. If it is missing, the embedded Microsoft bootstrapper needs an
internet connection during installation; Cairn.md itself works locally after
the prerequisite is installed.

The installed workflow, v0.1.0 upgrade path, and embedded Microsoft-signed
bootstrapper are verified in Windows CI. GitHub's Windows Server runners cannot
remove WebView2, so this prerelease has not yet executed the installer on a clean
Windows client with the runtime absent.

## Scope boundaries

- Windows x64 is the supported platform for this release.
- Projects remain top-level only; nested projects, tags, and search are planned
  for v0.2.0.
- Local Git history and historical diffs are planned for v1.0.0.
- HTML, front matter, math-like syntax, and other ambiguous blocks may require
  Source mode so Cairn.md can preserve them safely.

See the [user guide](https://github.com/moosicalbovine/Cairn.md/blob/v0.1.1/docs/USER_GUIDE.md)
and [troubleshooting guide](https://github.com/moosicalbovine/Cairn.md/blob/v0.1.1/docs/TROUBLESHOOTING.md)
for details.
