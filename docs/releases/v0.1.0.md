# Cairn.md v0.1.0 — local Markdown library MVP

Cairn.md v0.1.0 is the first usable Windows MVP. It brings Markdown files from
scattered folders into one local library where they remain ordinary, portable
`.md` files.

## Highlights

- Create top-level projects beneath a library folder you choose.
- Import Markdown through the file picker, drag and drop, or import-only tracked
  PC folders. Every import is a copy; Cairn.md does not edit the original.
- Read and edit rendered Markdown directly in Visual mode, with familiar
  formatting controls and a Source mode for exact syntax.
- Keep the project contents list visible while editing, or collapse it for more
  writing space.
- Rely on always-on autosave, durable recovery after forced termination, and
  protection when another application changes the file.
- Choose Light, Dark, or Follow Windows appearance.

## Install

Download the `.exe` and matching `.sha256` file from this release. Verify the
checksum, then run the installer. It installs for the current Windows user and
does not require administrator credentials.

This early installer is **unsigned** and may trigger a Microsoft Defender
SmartScreen warning. Verify that it came from this GitHub release and that its
SHA-256 checksum matches before deciding whether to run it.

Cairn.md uses Microsoft Edge WebView2. Most current Windows systems already have
the runtime. If it is missing, the embedded Microsoft bootstrapper needs an
internet connection during installation; the application itself works locally
after the prerequisite is installed.

The installed workflow and the embedded Microsoft-signed bootstrapper are
verified in Windows CI. GitHub's Windows Server runners cannot remove WebView2,
so this prerelease has not yet executed the installer on a clean Windows client
with the runtime absent. That clean-client check remains open before a stable
release.

## Data ownership

Your Markdown remains in the library folder you select. Uninstalling Cairn.md
does not remove that folder. Back up the library like any other document folder.
Private provenance and recovery metadata remain in Cairn.md's local app-data
directory and are never inserted into shared Markdown files.

## Scope boundaries

- Windows x64 is the supported platform for this release.
- Projects are top-level only; nested projects, tags, and search are planned for
  v0.2.0.
- Local Git history and historical diffs are planned for v1.0.0.
- HTML, front matter, math-like syntax, and other ambiguous blocks may require
  Source mode so Cairn.md can preserve them safely.
